# KINGDOM 4169 — Community Portal

A web portal designed for the KINGDOM 4169 community, featuring a themed interface and community-oriented tools.

## Technologies

- HTML
- CSS
- JavaScript
- Tailwind CSS
- Firebase SDK
- html2pdf.js

## Getting Started

1. Clone the repository.
2. Open `index.html` in a browser or use a local development server.
3. Configure Firebase if you intend to use features that depend on it.

## Security

- Configure Firebase security rules appropriately.
- Never commit private credentials or secret keys.
- Test user input handling and PDF export functionality before deployment.
